Kanpe

時間で切り替わる台本表示

発表開始からの経過時間に合わせて、台本が自動で次のパートへ切り替わるカンペツール。 一覧・編集・発表の3モードを備え、台本は自分のブラウザにだけ保存されるので、 同じURLを配っても中身が他人に見えることはありません。

経過時間で自動切替 全画面プレゼン 5秒刻みドラッグ調整 キーボード操作 AI変換プロンプト同梱 ローカル保存
開く ソース
公開中

Mock Exam

さまざまな分野に使える模擬試験

組み込みの問題集や自作の問題集で、選択式の模擬試験に挑戦できるクイズツール。 JSONファイルやテキストから問題集を追加でき、回答後は正誤と解説を確認できます。 問題集と受験結果はブラウザに保存され、結果はJSON / CSVで書き出せます。

ランダム出題 問題集インポート 正誤・解説表示 受験結果を保存 JSON / CSV 出力 ローカル保存
開く ソース
公開中

FlowDraft

システム設計フローチャート

開始・終了・処理・分岐・DB・API・ループなどのノードを並べて設計図を描くツール。 ビルド不要のバニラJSで、スマホのタッチ操作にも対応。 描いた図はURLに埋め込んで共有でき、PNG / SVG / JSON で書き出せます。

7種のノードプリセット 無制限 Undo / Redo ミニマップ PNG / SVG / JSON 出力 共有URL モバイル対応
開く ソース
公開中

Codex Pet Playground

スプライトシートの動作確認ビュワー

Codex Pet のスプライトシートを読み込んで、9種類の動きや16方向の向きを実際に動かして確認できるツール。 スマホではレバーとボタンのアーケード風コントローラで操作でき、 読み込んだファイルは一切アップロードされず、ブラウザの中だけで処理されます。

フォルダごと読み込み v1 / v2 自動判定 アケコン風コントローラ 16方向の向き確認 自動フィット表示 外部送信なし
