AIに聞いてまとめてもらった Markdown を、変換せずにそのまま置けるようにしてあります。

## 手順は2つだけ

1. Markdown ファイルを `lab/notes/` に置く
2. `lab/notes.json` に4〜6行の項目を1つ足す

HTML への変換は不要です。ブラウザ側で読み込むときに描画しています。

## notes.json の書き方

配列の中に、こういうブロックを1つ足すだけです。

```json
{
  "title": "CSSのz-indexが効かないとき",
  "desc": "スタッキングコンテキストの話",
  "file": "notes/z-index.md",
  "type": "md",
  "tags": ["CSS", "レイアウト"],
  "date": "2026-08-20"
}
```

各項目の意味は次のとおりです。

| キー | 必須 | 内容 |
|---|---|---|
| `title` | 必須 | 一覧に大きく出るタイトル |
| `file` | 必須 | `lab/` から見た相対パス |
| `type` | 必須 | `md` か `html` |
| `desc` | 任意 | タイトルの下に出る一行説明 |
| `tags` | 任意 | 絞り込み用。いくつでも |
| `date` | 任意 | `YYYY-MM-DD`。新しい順に並ぶ |
| `hidden` | 任意 | `true` なら一覧とトップでは非表示。URLからは閲覧可能 |

末尾の項目にカンマを付けるとJSONとして壊れて一覧が真っ白になります。そこだけ注意。

## すでにHTMLにしたものを置きたいとき

`type` を `html` にすれば、変換済みのファイルへ直接リンクします。

```json
{
  "title": "スクロール連動アニメーションの練習",
  "file": "notes/scroll-anim.html",
  "type": "html",
  "tags": ["JavaScript"],
  "date": "2026-08-18"
}
```

この場合、そのHTMLの見た目は自前です。共通のデザインを当てたければ、`<head>` に次の1行を入れておくと配色とテーマ切替が揃います。

```html
<link rel="stylesheet" href="../../assets/base.css">
```

## 使える記法

GitHub Flavored Markdown に対応しています。表、チェックリスト、打ち消し線、コードブロックはそのまま書けます。

見出しが `##` と `###` あわせて2つ以上あると、画面右に目次が自動で出ます。長いメモほど効いてきます。

## 公開範囲について

このページは GitHub Pages で公開されているため、**URLを知っていれば誰でも読めます**。検索避け（`noindex`）は入れてありますが、非公開ではありません。人に見せたくない内容は置かないでください。
